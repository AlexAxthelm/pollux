# Colorscheme
---
priority: mid
---

Note this is mid priority not because it's important, but because I don't want
to go back after the fact and update all the old color definitions in the UI
(there will be less to do there if we handle this sooner).

The color scheme of the app should be configurable, with some suggested
palletes/Colorschemes

internally, I expect that these will use the `base16` nomenclature (`base00`,
`base05`, etc), with the meanings mapped to what is semantically useful in app.

That gives us access to a good library of existing options (including my beloved
solarized), but also a useful framework for users to specify their own.
