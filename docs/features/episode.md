# Episodes
---
priority: MVP
---

Episodes are the atomic unit of content.

Episodes — I think the interface for an episode should be fairly simple. Most of the time I am going to want to see episodes as elements in a list (scrollable), with the title, usually the episode art, and any metadata such as description, date, release duration. If there's an episode number, that would be cool to include in there.

When I click on that, I should get sort of a menu where the default/main action is like "play," but I would also be able to have a more context menu that includes things like: download this episode, delete a downloaded episode, mark as played, mark as unplayed. If I do tagging at some point — add/remove tags, being able to add it to a particular playlist for like episode-specific playlists would be cool.

* OPEN QUESTION: Can we check if an episode is available on server without downloading?

## behavior

### Favorite (star)

mark an episode with a star (or other flag) to distinguish it from other
episodes as a favorite.
Can be used to help control playlist/download behavior

## UI 

### List view (single row)

Small art, play button, title, three-dots/share menu, played status,
download status, duration, position if partially played


### Details view (full page)

See Album art, show notes, chapters, etc.
