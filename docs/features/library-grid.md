# Library Grid view

The entries in the library (playlists and subscritpions) can be presented as
lists (default) or in a grid view.

When grid view is active a card is visible, with the playlist/show icon/art and
title (by default) with a small border (color indicating the type). The general
section/scroll behavior should be the same as the list view.

The user can configure the information on the cards (i.e. turn off the art, add
other summary infor that might be on the list view entries) (the card has
comparable functionality to the list entries, but is tall and narrow, rather
than short and wide)

In the grid view, the user can select the density (2, 3, 4 wide)
