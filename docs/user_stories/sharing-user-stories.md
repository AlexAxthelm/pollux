## User Stories: Sharing

As a listener
I want to share the episode
so that I can tell my friends about interface

As a listener
I want to share a particular spot in the episode
so that I can point someone to a spot in an episode

As a user
I want to share a playlist
so that I can have my friends listen along

As a user
I want to share the settings for a playlist
so that I can show how it's constructed
