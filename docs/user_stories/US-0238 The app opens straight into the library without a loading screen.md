As a User
I want a cold start to drop me into the library, and returning to an app that is already open to show what I was looking at, with no loading screen
so that the app is ready the moment I open it

Note: both should be effectively instant on a human timescale. Today the library shows a spinner while the subscriptions load, so this is not yet true ([[app-startup]]).
