# User Stories: Playlist

As a curator
I want a way to create a playlist
so that I can have an ordered set of episodes that will play consecutively

As a listener
I want to play a playlist
so that I can listen all the way through

As a listener
I want to change playlists 
so that I can listen to something different 

As a listener 
I want to play episodes from a single podcast 
so that I can listen to a single show

As a curator
I want to include multiple podcasts
so that I can hear episodes from multiple shows

As a curator
I want to filter episodes in the playlist
so that I have finer control over what I listen to 

As a curator
I want to add specific episodes to the playlist
so that I can have control over what I listen to 

As a curator
I want to change the sorting order of the playlist
so that I control what sequence they play in 

As a curator
I want to reorder specific episodes
so that I can change what plays next

As a curator
I want to control playback settings for the playlist
so that I can control behavior when listening to it

As a curator
I want to have apply multiple sorts
so that I can have more control over the list 

As a curator
I want to have multiple filters
so that I can better control what is in the list

As a curator
I want to include other playlists
so that I can inherit their filters and sorts

As a curator
I want sensible "quick options"
so that I can start a playlist effectively

As a curator
I want to easily include old episodes
so that I can work through backlogs

As a curator
I want to preview what the playlist will include
so that I can know what to expect in the list 

As a curator
I want to include a mix of both old and new episodes
so that I can keep up to date while working on archives

As a curator
I want to prioritize certain shows
so that I can listen to them first
