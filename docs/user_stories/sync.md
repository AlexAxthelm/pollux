# User Stories: Sync

As a user with multiple devices
I want my subscriptions to sync across devices
so that I can listen on any of them

As a user with multiple devices
I want my settings to sync across devices
so that I have consistent behavior

As a user with multiple devices
I want my playback position to sync across them
so that I can resume listening on another device

As a user with multiple devices
I want to easily see what I'm listening to on each
so that I can choose what I want to resume

## Per-device control

As a user with multiple devices
I want to control my settings per-device
so that I can manage them individually

As a user with multiple devices
I want to control which episodes get downloaded to each device
so that I can manage listening on each

As a user with multiple devices
I want my playback position to point to what I was last listening to on this
device
so that I can resume listening where I was on this device
