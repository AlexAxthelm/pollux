# User Stories: Settings

As a User
I want to set settings once, and have them generally be followed
so that I know what to expect from the app

As a curator
I want to control settings when making playlists
so that I can customize my experience
Note: this is for changing settings like skip interval and autoplay on a
playlist environment; list filtering and sorting is in `playlists.md`

As a listener
I want to override the default settings for an episode
so that I can listen to an episode comfortably

As a curator
I want to control settings for a show
so that I can adjust to a publisher's style

As a curator
I want to use a show's default settings in playlists
so that I don't have to worry about adjusting everything individually

As a listener
I want an episode to follow a show's default behavior
so that I know what to expect from a show

As a User
I want to know when new settings are available
so that I don't have to regularly explore the settings menu

As a User
I want to have a central zone for controlling settings
so that I don't have to struggle to find control surfaces

As a User
I want to search for a settings option
so that I can find what I'm looking for quickly

As a User
I want more powerful controls hidden, but accessible
so that I have to opt-in to things that may cause problems for me

As a user
I want to be able to show powerful controls all the time
so that I can permanently opt in
(sudo vs login)

As a user
I want to easily return a setting to default
so that I don't need to know what a sensible default is

As a user
I want to be able to easily undo a settings change
so that I can fix mistakes easily

As a User
I want sensible defaults for settings
so that I don't have to have strong opinions on podcast app design

As a User
I want to see if I've adjusted a setting from default
so that I can easily tell what I've customized

As a User
I want to know if a default setting changes
so that I can determine if I like the old behavior

As a user
I want new settings to be opt-in
so my player doesn't change unexpectedly

As a User
I want to change global settings and have that change be respected
so that I can control my listening

As a user
I want to see when a setting has been changed from global
so that I know what to expect

As a user
I want to know if I've changed a global setting
so that I can understand why the system is behaving the way it is

As a developer
I want to export settings
so that I can include them in bug reports
