# User Stories: Appearance

As a user 
I want to change the color theme of the app
so that it feels like it's mine

As a curator
I would like to switch between a "grid view" and "list view"
so that I can either scan visually, or look through details

As a curator
I would like to set what details are visible about episodes
so that I can surface information that's relevant to me

As a curator
I would like to set what details are visible about subscriptions
so that I can surface information that's relevant to me

As a user
I would like to control the size of UI elements
so that I can browse comfortably

As a user
I would like the default UI size to inherit from system
so that the app doesn't need special treatment
