# User Stories: playback

As a listener,
I want to hit play on an episode I don't have yet, and have the episode start playing
so that I can listen to the episode


As a listener
I want to hit play on an episode I have locally, and have the episode start playing
so that I don't experience friction

As a listener
I want to be able to pause
so that I can stop listening

As a listener
I want to be able to resume a paused episode at the same spot
so that I can continue listening

As a listener
I want to have playback resume at the spot I left an episode
so that I can come back to it after listening to something else

As a listener
I want to have playback continue in the background
so that I can do other things with my phone

As a listener
I want to control playback using the system interface
so that I don't have to reopen Pollux to control it.

As a listener
I want playback ton continue when the phone is locked
so that  don't have to have my screen on all the time

As a listener
I want to have another episode play automatically when the current one is done
so that I don't have to be alone with my thoughts

As a listener
I want to skip chapters
so that I can move about the episode

As a listener
I want to adjust the time jump for skipping
so that I have control over how far I skip

As a listener
I want to adjust playback position manually
so that I can jump to a specific point in episode

As a listener
I want to adjust playback speed
so that I can listen to more episodes in the same (wall) time

As a listener
I want to see information about the episode that is playing
so that I can be informed

As a listener
I want to track my listening
so that I can better understand my habits

As a listener
I want to see my current playback position
so that I can be informed

As a listener
I want to see how much is left in the episode
so that I can decide if I want to keep listening

As a listener
I want to see when the current episode will finish
so that I can see where it fits in my day

As a listener
I want to set a timer for playback
so that it doesn't play while I'm sleeping

As a listener
I want to stop playback at end of episode
so that playback doesn't continue automatically

As a listener
I want to control the skip intervals for different shows
so that I can match behavior to the show

As a listener
I want to queue an episode
so that it plays without changing the playlist I'm listening to 

As a listener
I want to see what's playing at all times, even if I'm not looking at the main player view
so that I can quickly control playback

As a listener
I want to select the output device (Bluetooth, AirPlay, speaker, etc)
so that I can listen how I want
