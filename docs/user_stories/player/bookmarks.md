## User Stories: Bookmarks

As a listener
I want to bookmark a spot in an episode
so that I can come back to it later

As a listener
I want to take a screenshot of playback indicator and have it create a bookmark
so that I can have a low friction way of bookmarking

As a listener
I want to have a button that adds a bookmark at the current playback head
so that I can have a low friction way of bookmarking

As a curator
I want to jump quickly back to a bookmark
so that I can relisten to what I saved

As a curator
I want to see the transcript at a bookmark's timestamp
so that I can read what I wanted to saved

As a curator
I want to save a bookmark from the transcript
so that I can save a segment

As a curator
I want to have bookmarks optionally define a span
so that I can save a segment, rather than a point

As a curator
I want to share my bookmark
so that I can point other people to a particular point in an episode
