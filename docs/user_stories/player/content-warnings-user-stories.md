## User Stories: Content warnings

As a user
I want to see content warnings for episodes
So that I can determine if I want to listen

As a user
I want to filter episodes with content warnings
So that I can avoid triggering episodes

As a user
I want to parse episode descriptions for content warnings
so that publishers can warn in different formats

As a User
I want to identify different types of content warnings
so that I can respond differently to them
