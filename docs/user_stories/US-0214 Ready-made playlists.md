As a curator
I want useful ready-made playlists that don't need configuring
so that I can start listening quickly
(All subscriptions, Downloaded, in progress, etc)

Related, but distinct from [[US-0209 Playlist quickstarts]]. That one is about getting people the right tools to composite their own playlists, this is about having a sensible set of playlists already made that they can use without needing to configure more. The same solution may solve both stories.
